## 8. Questions Still Open

All 10 items in `docs/clem/reference.md` Section 10 are settled by the 62 rules above. The only CLEM surface areas not exercised by `clem_semantics.py` are:

1. **Spatial / Geohash functions (`area`, `distance`, `close_to`, `crosses`, `overlap`, `within`, `num_points`, `to_geohash`, `stb_centroid_latitude`, `stb_centroid_longitude`)**: require geospatial list/shape fields and a configured coordinate system (`geo_type`, `coordinate_system`), which are outside the scalar tabular types currently in scope.
2. **Context-bound special fields (`@TARGET`, `@PREDICTED`, `@PARTITION_FIELD`, `@TRAINING_PARTITION`, `@TESTING_PARTITION`, `@VALIDATION_PARTITION`, `@MULTI_RESPONSE_SET`)**: only valid inside downstream Analysis user-defined expressions, Partitioned streams, or Multiple Response Set metadata contexts.
3. **`time_hours_difference` / `time_mins_difference` / `time_secs_difference` with stream rollover enabled**: default stream behavior is non-rollover (exact difference); interaction with the stream `rollover` property was not separately probed.
